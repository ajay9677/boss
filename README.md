# BOSS-FASHION STORE

## 🛍️ Project Overview

**BOSS-FASHION STORE** is a modern and responsive e-commerce website built using **HTML, CSS, and JavaScript**. The website provides a clean shopping experience with multiple pages, product collections, search functionality, category filtering, and a responsive design that works across desktop, tablet, and mobile devices.

## 🔎 Search Functionality

The Collections page includes a JavaScript-based search feature. Users can enter a product name in the search box, and the displayed products are dynamically updated according to the search text.

## 🔽 Filter Functionality

Products can be filtered according to their categories. JavaScript handles the filtering dynamically without requiring the page to reload.

## 📱 Responsive Design

The website is designed to provide a smooth experience on:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

CSS media queries are used to adjust the layout, navigation, product grid, images, and other components according to screen size.

## 🚀 How to Run the Project

git clone https://github.com/ajay9677/boss

4. Navigate between:

   * Home

   * Contact Us
